#  Client and Server Roles

### 1. What is a Host?
- All computers that are directly connected to a network and take part in communication are called **Hosts**.
- Hosts can send and receive messages on the network.
- In modern networks, a host can act as:
    - Client
    - Server
    - Both
- **The software installed on the computer decides its role.**

### 2. What is a Server?
- A Server is a host that has **server software** installed.
- Its job is to **provide information** to other hosts.
- Each service needs its own server software. For example, to provide web service, a host needs web server software.
- Every website you visit online is provided by a server that is located somewhere on the internet.

### 3. What is a Client?
- A Client is also a host, but it has **client software** installed.
- Its job is to **request and display** information from the server.
- Example of client software: A web browser like Chrome, Firefox, Safari, or Internet Explorer.

### 4. Types of Servers

| Type | Description |
| :--- | :--- |
| **Email Server** | The email server runs email server software. Clients use mail client software, like **Microsoft Outlook**, to access email on the server. |
| **Web Server** | The web server runs web server software. Clients use browser software, like **Internet Explorer / Chrome**, to access web pages on the server. |
| **File Server** | The file server stores company and user files in one central place. Client devices access these files using software like **Windows File Explorer**. |
