# Common Methods of Data Transmission

## 1. What is Data Transmission?
After data is converted into bits (0 and 1), it must be converted into **signals** so it can travel across network media to its destination.

### Key Terms:
- **Media:** The physical medium on which signals are transmitted.
    - Examples: copper wire, fiber-optic cable, air (for wireless).
- **Signal:** Electrical or optical patterns that represent digital bits. It travels from source to destination.
- **Important Point:** A signal can be converted many times before reaching the destination. For example, from electrical to light to radio wave, as media changes.

---

## 2. Three Common Methods of Signal Transmission

There are three main methods used in networks:

### 1. Electrical Signals
- **How it works:** Data is represented as electrical pulses.
- **Medium Used:** Copper wire / Copper cables.
- **Example:** Ethernet cables (LAN cables).

### 2. Optical Signals
- **How it works:** Electrical signals are converted into light pulses.
- **Medium Used:** Fiber-optic cable.
- **Example:** Long-distance internet connections.

### 3. Wireless Signals
- **How it works:** Transmission uses electromagnetic waves through the air.
- **Medium Used:** Air.
- **Types:** Infrared, Microwave, Radio waves.
- **Example:** Wi-Fi, Bluetooth, Mobile Data.


## 3. Real-World Usage

- **Homes and Small Businesses:** Mostly use **Copper wires (cables)** or **Wi-Fi (Wireless)** connections.
- **Large Networks / ISPs:** Use **Fiber-Optic cables** because they can carry signals reliably for longer distances and at high speed.

> **Summary:** Data -> Bits -> Signals (Electrical / Light / Radio) -> Travels on Media (Copper / Fiber / Air) -> Destination.
