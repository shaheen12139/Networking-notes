# 2.2.2 Network Infrastructure

### What is Network Infrastructure?
- The path a message takes from source to destination.
- It can be simple like one cable connecting two computers.
- Or it can be complex like a network that spans the whole globe.
- Network Infrastructure is the **platform that supports the network**.
- It provides a stable and reliable channel for communication to occur.

### Three Categories of Network Hardware
Network infrastructure has 3 main categories of hardware components:

#### 1. End Devices
- Devices that users are most familiar with.
- Also called Hosts.
- Example from figure: Desktop Computer, Laptop, Printer, IP Phone, Wireless Tablet, TelePresence Endpoint, Security Camera

#### 2. Intermediary Devices
- Devices that connect end devices and manage data flow.
- Example from figure: Wireless Router, LAN Switch, Router, Multilayer Switch, Firewall Appliance

#### 3. Network Media
- The channel through which messages travel.
- 3 Types:
    - **Wireless Media** -> Represented by wavy line ( ~~~~ ). Uses invisible radio frequencies or infrared waves.
    - **LAN Media** -> Represented by straight line ( ---- ). Used for Local Area Network.
    - **WAN Media** -> Represented by zigzag line ( -Z- ). Used for Wide Area Network.

> **Important Point:** Devices and media are the physical elements, or hardware, of the network. Most hardware is visible like laptop, PC, switch, router, cable. But wireless media is not visible because messages travel through the air.

# 2.2.3 End Devices

### What are End Devices?
- The network devices that people are most familiar with.
- Also called **Hosts** or **End Hosts**.
- They form the interface between users and the underlying communication network.
- An end device is either the **source** or the **destination** of a message.

### Examples of End Devices
1.  **Computers:** Workstations, Laptops, File Servers, Web Servers
2.  **Network Printers**
3.  **Telephones and Teleconferencing Equipment:** IP Phones, TelePresence
4.  **Security Cameras**
5.  **Mobile Devices:** Smart Phones, Tablets, PDAs, Wireless debit/credit card readers, Barcode scanners

### How End Devices Communicate?
- To uniquely identify each host, **addresses** are used.
- When a host initiates communication, it uses the address of the destination host to specify where the message should be sent.
